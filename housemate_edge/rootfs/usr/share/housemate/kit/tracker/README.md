# Tracker

Bigger work is tracked here as markdown, one file per ticket in `tracker/`,
named `NN-short-title.md`, each starting with:

```
---
status: open        # open, in-progress, done
---
# Title
What and why. Acceptance criteria as a checklist.
```

Change the status as work moves and commit the change. For anything bigger
than a quick change, write the ticket first, then do it.
